# ProjectFigma

A collection of my first front-end projects — responsive landing pages coded from
[Figma](https://figma.com) design layouts. Each one is a static site built with plain
HTML, CSS and [Bootstrap 5](https://getbootstrap.com/), and is published with GitHub Pages.

> These are early learning projects, so the focus is on turning a pixel-perfect Figma
> layout into working, responsive markup rather than on tooling or JavaScript.

## Projects

| # | Project | What it is | Stack | Live demo |
|---|---------|------------|-------|-----------|
| 1 | **[Alivio](Project1/)** | Landing page for a stress-management journaling app | HTML5 · Bootstrap 5.0.0-beta2 · custom CSS/JS | [Open ↗](https://pavloseniv.github.io/ProjectFigma/Project1/) |
| 2 | **[Barber](Project2_Barber/)** | Landing page for a barbershop | HTML5 · Bootstrap 5.0.1 · WebP · custom CSS/JS | [Open ↗](https://pavloseniv.github.io/ProjectFigma/Project2_Barber/) |

Each project has its own `README.md` with full details.

## Running locally

The projects are static, so no build step is required to view them. Clone the repo and
open a project's `index.html` in a browser, or serve it with any static server:

```bash
git clone https://github.com/pavloseniv/ProjectFigma.git
cd ProjectFigma

# open directly…
open Project1/index.html          # macOS

# …or serve the whole repo
python3 -m http.server 8000       # then visit http://localhost:8000/Project1/
```
